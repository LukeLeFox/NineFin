NineFin 0.7.2 · current release

NineFin is a native Jellyfin client built specifically for legacy iPhone and iPad devices running iOS 9. It is written in Objective-C with Theos and targets 32-bit ARMv7 hardware.

01 About NineFin
01

Jellyfin on legacy Apple hardware

iOS 9

English A native Jellyfin experience for legacy devices such as the iPhone 4S and older iPads, without depending on a modern browser or a current App Store client.

Italiano Un client Jellyfin nativo pensato per riportare lo streaming sui vecchi iPhone e iPad con iOS 9.

02

Features

native UIKit
  • Jellyfin login with sessions and credentials stored in the iOS Keychain
  • Multiple saved servers and selectable default server
  • Continue Watching, Next Up, recent movies and recent series
  • Movies, shows, seasons and episodes
  • Global search and favorites
  • Native HLS playback with configurable streaming quality
  • Playback progress synchronization and watched-state handling
  • Audio-track and subtitle selection

Release Prebuilt IPA files are published with NineFin releases, so compiling from source is optional. Open the latest release ↗

Install On legacy iOS 9 hardware, installation requires a compatible IPA sideload method. A jailbroken device with AppSync Unified is the recommended setup used during testing.

current_release=0.7.2
bundle_id=dev.luke.ninefin
deployment_target=iOS 9.0
architecture=armv7
package=IPA
04

Build from source

Theos
$FINALPACKAGE=1 make package

Requires Theos with an iOS 9.2 SDK. The project intentionally keeps its legacy deployment settings; changing the target SDK, deployment target or architecture may break compatibility.
