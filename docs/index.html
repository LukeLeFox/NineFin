NineFin

A native Jellyfin client for legacy iOS 9 devices.

Download IPA View source on GitHub
Ready-to-install IPA available. NineFin releases include a prebuilt IPA for users who do not want to compile the app themselves.

Jellyfin on old iPhone and iPad hardware

NineFin is built specifically for legacy Apple devices running iOS 9. It targets 32-bit ARMv7 hardware and provides a native Jellyfin experience for devices such as the iPhone 4S and older iPads.

Features

  • Jellyfin login with Keychain-backed sessions
  • Multiple servers
  • Continue Watching and Next Up
  • Movies, TV shows, seasons and episodes
  • Global search and favorites
  • Native HLS playback
  • Playback progress synchronization
  • Audio and subtitle selection
  • Configurable streaming quality

Compatibility

  • iOS 9.0 or newer within the legacy ARMv7 target
  • 32-bit ARMv7
  • iPhone and iPad
  • IPA package format

Download NineFin

The latest tested build is available from GitHub Releases. The current release includes a precompiled .ipa file.

Build from source

Developers can build NineFin using Objective-C, Theos and an iOS 9.2 SDK. Source code is available in the NineFin GitHub repository.
